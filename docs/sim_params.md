# Параметры для MuJoCo (NeuroPaw v6)

Источник: `scripts/v6_calc.py` по `robodog_v6.blend`. Система координат: X вперёд, Y влево, Z вверх; оси звена совпадают с мировыми в позе покоя (ноги прямые). ЦМ звена — от оси его сустава, мм. Инерция — относительно ЦМ звена, кг·м² (оценка по точечным массам деталей, без собственной инерции деталей — занижение у крупных деталей корпуса).

## Колено

Привод через четырёхзвенник: r1 15.0 мм, r2 29.0 мм, тяга 55.0 мм. Передача нелинейная, таблица κ → (угол сервы, передача) — `docs/knee_linkage.md`; в стойке 2.09, на шаге ≥ 1.94. Ход κ 65…128° (кость: -128…-65°), упор 128.5°, мёртвая точка тяги 130.04°. В MuJoCo: joint колена с `gear` по таблице или `ctrlrange` сервы + tendon/таблица.

## Пружина колена (пружинный элемент сустава)

Торсион на каждом колене: жёсткость **0.5365 Н·м/рад**, свободное положение при κ = 40° (натяг 25° при κ 65°). Момент разгибает колено: τ = k·(κ − κ_free).

```xml
<joint name="knee" ... stiffness="0.5365" springref="-0.6981"/>
```
Кость колена φ = −κ, поэтому springref = −κ_free (рад). Демпфирование пружины не задаём.
