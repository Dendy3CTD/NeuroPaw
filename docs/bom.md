## Проверка количеств

- **Качалки 25T:** 15 (все MG996R и DS3235MG, на тягах колена тоже металлические) + 1 запас = 16.
- **625ZZ:** 22 в модели (отведение 4, бедро 4, колено 8, позвоночник 2 + 2, наклон шеи 2) + 2 запас = 24; куплено 30.
- **MR683ZZ:** 2 из 2. **51100:** 1 из 2. **Динамик:** 1 из 2. **SN65HVD230:** 4 из 4. **INMP441:** 2 из 2.
- **PETG:** детали ≈ 0.98 кг, с поддержками (+15 %) и перепечаткой (+20 %) ≈ 1.35 кг — 2 кг хватает. **TPU:** ≈ 12 г из 500.
